# 🚀 Reem K - AI/ML Engineer Portfolio

A modern, interactive 3D portfolio website showcasing my journey as an AI/ML Engineer, featuring real-world projects in Computer Vision, Healthcare AI, and Real-time ML systems.

## ✨ Features

- **Interactive 3D Elements** - Engaging 3D models and animations using Three.js
- **Responsive Design** - Seamless experience across all devices
- **Project Showcase** - Detailed presentation of AI/ML projects with live GitHub links
- **Achievement Gallery** - Certificates, hackathon wins, and leadership roles
- **Tech Stack Visualization** - Animated display of technical skills
- **Contact Form** - Direct email integration via EmailJS
- **Smooth Animations** - Powered by Framer Motion for fluid transitions

## 🛠️ Tech Stack

### Frontend
- **React.js** - UI library
- **Three.js & React Three Fiber** - 3D graphics and animations
- **Framer Motion** - Animation library
- **TailwindCSS** - Styling

### Technologies Showcased
- **Languages:** Python, Java, C Programming, JavaScript
- **ML/AI:** TensorFlow, OpenCV, Computer Vision
- **Backend:** FastAPI, MySQL, MongoDB
- **Tools:** Docker, Git, GitHub, React

### Build Tools
- **Vite** - Fast build tool and dev server
